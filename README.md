# 测力计实时读取

## 首次运行

在 PowerShell 中执行：

```powershell
cd D:\测力计读取
py app.py
```

在窗口中输入串口号（例如 `COM14`），点击“连接”。连接后会显示测力计的实时牛顿值、原始值、最后更新时间和接收帧率。

## 已确认的设备协议

- 串口设置：`115200, 8N1`，无流控，RTS 开启、DTR 关闭。
- 启动读取：发送 ASCII 字符 `e`（十六进制 `65`）。
- 力值记录：`55 01 ±ddddd`，例如 `55 01 2B 30 30 30 30 30` 表示 `+00000`。

仪器发送的是原始编码。原厂程序会把符号后的五个字节各取低 4 位，按十六进制拼成原始计数；当前设备的原厂倍率为 `0.001 N/count`。因此换算公式为 `N = 有符号原始计数 × 0.001`。例如编码 `-0019>` 的低 4 位为十六进制 `0019E`，即 `-414 counts`，显示为 `-0.414 N`。界面顶部默认的“每计数牛顿值”已设为 `0.001`。

运行前请关闭原厂软件；同一串口不能被两个程序同时打开。
